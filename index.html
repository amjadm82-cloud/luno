    KI (Claude)

    Von console.anthropic.com → API Keys.

    Stimme

    Tipp für Samsung: Einstellungen → Allgemeine Verwaltung → Text-zu-Sprache → „Sprachausgabe von Google“ wählen und die deutsche Stimme in hoher Qualität laden.
    Gratis-Schlüssel von aistudio.google.com/apikey. Für Chirp muss im selben Google-Projekt die „Cloud Text-to-Speech API“ aktiviert sein.
    In der Voice Library nach „German child“ oder „German kids storyteller“ suchen und die Voice-ID kopieren.

    Bilder

    Ohne Schlüssel kommen die Bilder von Wikipedia und Openverse. Mit einem Schlüssel nimmt Luno zuerst diese Quelle.
    Spielt die Online-Stimme etwas höher ab. 5–10 % klingt meist am natürlichsten.

    Familien-Link

    Erstellt einen Link mit diesen Einstellungen. Auf einem anderen Gerät öffnen, und Luno ist sofort startklar. Den Link nur in der Familie teilen, er enthält die Schlüssel.
