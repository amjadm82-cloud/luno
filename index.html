    Technik (nur einmal einrichten)

    1. KI-Antworten (Claude)

    console.anthropic.com → API Keys → Create key. Beginnt mit „sk-ant-“.

    2. Stimme

    Tipp Samsung: Einstellungen → Allgemeine Verwaltung → Text-zu-Sprache → „Sprachausgabe von Google“ wählen und die deutsche Stimme in hoher Qualität laden.
    Google Cloud Console → APIs & Services → Credentials → „Luno Stimme“ → Show key. Beginnt meist mit „AIza“.
    aistudio.google.com → API-Schlüssel → Schlüssel kopieren. Beginnt mit „AQ.“ oder „AIza“.
    In der Voice Library eine deutsche Kinder- oder Erzählerstimme suchen und die Voice-ID kopieren.
    Spielt die Online-Stimme etwas höher ab. 5–10 % klingt meist am natürlichsten.

    3. Bilder

    Jedes Bild wird vor dem Zeigen von Claude auf Kindertauglichkeit geprüft. Ohne Schlüssel kommen nur Wikipedia-Bilder.
    pixabay.com/api/docs (eingeloggt) → Abschnitt „Parameters“ → grün hinterlegt bei „key“.
    unsplash.com/oauth/applications → New Application → „Access Key“ kopieren.
    Pexels vergibt zurzeit keine neuen Schlüssel.

    Verbindungen prüfen

    Prüft jeden Dienst einzeln und zeigt, was funktioniert. Bei Problemen ein Foto davon an Claude schicken.
